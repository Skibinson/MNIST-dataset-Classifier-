# Классификатор рукописных цифр MNIST

Проект курсовой работы по теме «Нейронные сети и глубокое обучение».

Реализована полносвязная нейронная сеть для распознавания рукописных цифр из датасета MNIST. Код написан на чистом Python с использованием только библиотек NumPy и Matplotlib (без готовых фреймворков вроде TensorFlow или PyTorch).

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/Skibinson/MNIST-dataset-Classifier-.git
```

### 2. Создание виртуального окружения
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Обучение нейронной сети
```bash
python train.py
```
### 5. Демонстрация работы
```bash
python demo.py
```

### 6. Добавление своего примера
+ Создайте файл в Paint или любом другом графическом редакторе с разрешением 28x28
+ Нарисуйте свою цифру
+ Сохраните файл в ```my_digit/digit.png```
+ Запустите ```bash python demo.py```
